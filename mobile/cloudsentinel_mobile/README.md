# CloudSentinel Mobile

Native Flutter Android console for [CloudSentinel](../..). It reads the same
SQLite alert store as the Streamlit dashboard, through the FastAPI service.

## Requirements

- Flutter 3.47+ / Dart 3.13+
- Android SDK (API 36) and a JDK 17+ toolchain
- CloudSentinel API running and reachable from the phone

## Run

```powershell
flutter pub get
flutter run
```

Enter `http://<server-LAN-IP>:8080` and the API token. The phone must be on the
same network as the server.

Start the server with:

```powershell
python -m cloudsentinel serve --host 0.0.0.0 --port 8080 --token YOUR_TOKEN
```

Add `--allow-scan` to expose the in-app scan button.

## Build

```powershell
flutter analyze
flutter test
flutter build apk --release
# build/app/outputs/flutter-apk/app-release.apk
```

The repo copy lives at `../../dist/CloudSentinel-1.0.0.apk`. Release builds use
the generated debug signing config, which is fine for sideloading but not for
Play Store distribution.

## Structure

```
lib/
├── api.dart          typed client, models, error/time helpers
├── connection.dart   saved server + token
├── main.dart         app state, persistence, splash
├── theme.dart        neon palette, theme, glass panel
└── screens/
    ├── connect_screen.dart
    ├── dashboard_screen.dart
    ├── alert_detail_screen.dart
    └── settings_screen.dart
```

Launcher icons are generated by `python tool/generate_icons.py` (Pillow).
