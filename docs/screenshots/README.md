# Screenshots

The README shows two live captures of CloudSentinel. Drop the PNG files in this
folder using exactly these names:

| File            | What to capture                                                        |
|-----------------|------------------------------------------------------------------------|
| `dashboard.png` | The Streamlit console on the laptop showing a full ALERT FEED          |
| `phone.png`     | The Android app showing the live dashboard (or an alert detail screen) |

Easy way to make them:

1. Laptop: open the dashboard, arrange an interesting view, then press
   `Win + Shift + S` and drag over the window. Save as `dashboard.png`.
2. Phone: take a normal screenshot, send the file to the laptop (USB / Drive /
   WhatsApp to yourself), save as `phone.png`.
