# Screenshots

| File            | What it contains                                                       |
|-----------------|------------------------------------------------------------------------|
| `dashboard.png` | The Windows desktop app dashboard — captured automatically, see below  |
| `phone.png`     | The Android app dashboard (to be added)                                |

## Recreating `dashboard.png`

The image is regenerated by the repository's own automation — no manual
screenshot involved:

```
# API must be running (python -m cloudsentinel serve ...), then:
powershell -ExecutionPolicy Bypass -File scripts\capture_dashboard.ps1
```

The script creates a short-lived analyst token, launches `app\CloudSentinel.exe`
with `--screenshot`, waits for the capture, revokes the token and deletes the
temp file. The published crop shows the top of the dashboard only — the alert
feed lines contain the deployment's own identifiers and stay out of the repo.

## Adding `phone.png`

On the phone: open the CloudSentinel app, wait for the dashboard to load, take
a screenshot, send it to this machine and save it here as `phone.png`.
